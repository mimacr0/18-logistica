🚀 Guía de Integración Rápida

Para usar el widget QR en tu módulo, sigue estos pasos:

1

Añadir dependencia en el manifest

En el archivo __manifest__.py de tu módulo, añade widget_qr_attachments como dependencia:

# tu_modulo/__manifest__.py
{
    'name': 'Mi Módulo',
    'depends': [
        'base',
        'mail',
        'widget_qr_attachments',  # ← Añadir esta línea
    ],
    # ...
}
2

Añadir el widget en la vista XML

En la vista de formulario de tu modelo, añade el widget sobre cualquier campo de tipo Char, Text o Integer (normalmente name): 

<!-- tu_modulo/views/mi_modelo_views.xml -->
<record id="view_mi_modelo_form" model="ir.ui.view">
    <field name="name">mi.modelo.form</field>
    <field name="model">mi.modelo</field>
    <field name="arch" type="xml">
        <form>
            <sheet>
                <group>
                    <field name="name"/>

                    <!-- ✅ Solo esta línea es necesaria -->
                    <field name="name"
                           widget="qr_attachments"
                           nolabel="1"
                           invisible="not id"/>
                </group>
            </sheet>
        </form>
    </field>
</record>
3

Configurar la URL base

Ve a Ajustes → Técnico → QR Upload Settings y configura la URL externa de tu instancia de Odoo:

https://tu-dominio.com
⚠️ Importante: Sin esta URL configurada, el widget mostrará "URL not configured" y no generará el QR. Debe ser la URL pública accesible desde móvil.
✅ ¡Eso es todo! No necesitas crear campos extra en tu modelo, ni tokens, ni controladores. El módulo widget_qr_attachments se encarga de todo automáticamente.

⚙️ Arquitectura Interna

Entender cómo funciona internamente el módulo:

Componente Responsabilidad
qr.access.token Modelo que almacena tokens por (model, res_id). Genera tokens nuevos automáticamente al primer uso.
qr_widget.js Widget OWL backend. Llama a qr.access.token.get_or_create_token() para obtener el token y genera la URL del QR.
controllers/main.py Rutas públicas (auth='public'). Valida el token del QR y gestiona subida/listado/borrado de archivos.
upload_template.xml Interfaz móvil HTML independiente con soporte de cámara, subida de archivos, y toggle de modo oscuro.
upload_ui.js JavaScript frontend para la interfaz móvil. Gestiona la subida, listado y borrado de attachments vía JSON-RPC.

Flujo de Funcionamiento

1. Usuario abre formulario en Odoo
   ↓
2. Widget JS llama a qr.access.token.get_or_create_token()
   ↓
3. Se genera URL: https://dominio/qr_upload/mi.modelo/123?token=UUID
   ↓
4. Se muestra el QR en el formulario
   ↓
5. Usuario escanea QR con el móvil
   ↓
6. Se abre la página de upload (auth='public')
   ↓
7. Controlador valida el token contra qr.access.token
   ↓
8. El archivo se sube y se vincula al registro
   ↓
9. Se añade automáticamente a campos Many2many de ir.attachment

🔐 Seguridad

Escenario Acceso
Usuario interno de Odoo autenticado ✅ Acceso directo, no necesita token
Usuario público con token válido ✅ Acceso permitido (subir, ver, borrar attachments)
Usuario público sin token ❌ Acceso denegado
Token inválido o de otro registro ❌ Acceso denegado
⚠️ Seguridad: Cada par (modelo, registro) tiene un token único. Los tokens se generan como UUID v4 y se almacenan en la tabla qr_access_token. Los archivos subidos por QR se marcan como public=True en ir.attachment.

🔧 Configuración Avanzada

Parámetro del Sistema

Clave Valor Descripción
widget_qr_attachments.qr_external_base_url https://tu-dominio.com URL base pública para generar el enlace del QR. Obligatorio.

Campos soportados

El widget qr_attachments se puede usar sobre campos de tipo:

  • Char — Lo más común, se usa sobre el campo name
  • Text
  • Integer

El campo solo se usa como "soporte" para renderizar el widget. El QR se genera a partir del resModel y resId del registro, no del valor del campo.

❓ FAQ

¿Necesito añadir campos al modelo?

No. El modelo no necesita ningún campo extra. El módulo gestiona los tokens internamente en su propia tabla (qr.access.token).

¿Los archivos subidos por QR aparecen en el chatter?

Los archivos se vinculan como ir.attachment al registro (res_model / res_id). Además, si el modelo tiene campos Many2many('ir.attachment'), se añaden automáticamente.

¿Funciona sin conexión a internet?

No. El dispositivo móvil necesita acceso a la URL pública configurada para poder subir archivos.

¿Puedo personalizar la interfaz de subida?

Sí. Puedes heredar el template widget_qr_attachments.upload_mobile_template o modificar los estilos en static/src/frontend/scss/upload_ui.scss.

🔄 Regenerar Tokens

Puedes invalidar el QR actual y generar uno nuevo llamando a regenerate_token(). Esto es útil por seguridad cuando cambias de estado o quieres revocar el acceso al QR anterior.

Método disponible

Método Parámetros Retorna
regenerate_token(model_name, res_id) model_name (str), res_id (int) Nuevo token (str)

Ejemplo: Regenerar al cambiar de estado

# mi_modulo/models/mi_modelo.py
from odoo import models, api

class MiModelo(models.Model):
    _inherit = 'sat.repair.rma'  # o tu modelo

    def write(self, vals):
        res = super().write(vals)
        if 'state' in vals:
            for record in self:
                # Invalida el QR anterior y genera uno nuevo
                self.env['qr.access.token'].regenerate_token(
                    self._name, record.id
                )
        return res

Ejemplo: Regenerar desde un botón

# mi_modulo/models/mi_modelo.py
class MiModelo(models.Model):
    _inherit = 'sat.repair'

    def action_regenerate_qr(self):
        """Botón en la vista para regenerar el QR manualmente."""
        for record in self:
            self.env['qr.access.token'].regenerate_token(
                self._name, record.id
            )
        return True
<!-- mi_modulo/views/mi_modelo_views.xml -->
<button name="action_regenerate_qr"
        string="🔄 Regenerar QR"
        type="object"
        class="btn-secondary"/>
⚠️ Importante: Al regenerar el token, cualquier QR impreso o compartido anteriormente dejará de funcionar. El widget del formulario mostrará automáticamente el nuevo QR la próxima vez que se abra el registro.
